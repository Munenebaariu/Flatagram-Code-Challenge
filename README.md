# Flatagram-Code-Challenge

## Description
Flatagram - a simple web app that displays a photo, its title, number of likes, and comments.  
I practised working with JavaScript and a local JSON server to display data, handle user interactions and update the DOM.

Main features:
- View image data (title, photo, likes)
- View comments
- Like the image
- Add new comments

This project uses HTML, CSS, and JavaScript with fetch, to communicate with a local API created using json-server.


How It Works

1.When the page loads, it fetches image and comment data from http://localhost:3000.
2.The image title, likes, and comments appear on the page.
3.Clicking the heart increases the like count (on the frontend only).
4.Submitting a comment adds it to the page.
